# cloud_lib 开发约束

本文件沿用 designplugin_lib 的开发约束，并适配到 cloud_lib。

以下变更**必须由人工处理**，禁止在自动化开发中自行修改：

## 配置与数据

- 不随意修改 `setup.json` 中已发布配置键的名称、类型与默认值
  （`deepseek_app_*`、`silicon_app_*`）。
- 新增 / 删除 / 重命名配置键时，先停止改动并交由人工确认，
  同时检查 `README.md` 的配置表是否需要同步。
- 本库只读取 `info.db.setting`，不建表、不写业务数据；不得新增数据库写入逻辑。

## FFI 接口

- 不能调整现有 FFI 方法名，包括导出符号名（`chat_t2t`）、参数与返回值约定。
- 不能自行新增 FFI 方法。
- 需要新增或重命名接口时，先停止改动并交由人工确认。
- 对外 `json_out` 缓冲区约定见 [ffi-buffer.md](./ffi-buffer.md)：
  对外 1 MiB，调用 `database` / `plugin_lib` 时 1 MiB，各自使用独立常量。
- 响应结构固定为 `{ code, msg, data }`，成功 / 失败语义变更需人工确认。

## 错误码

- 已发布的错误码不得改号或改含义；新增错误码应落在对应区段并在
  `src/utils/errcode.rs` 与 `README.md` 的错误码表中同步。

## 原则

- 涉及上述变更，先说明需求与影响，由人工决定并手动实施。
- 其他实现细节可以正常修改，但不得顺带改动配置键、FFI 接口与错误码。
